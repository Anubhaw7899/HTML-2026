!DOCTYPE html - tells the browser:“This page is modern HTML5.”

meta charset="UTF-8" tells the browser to decode the HTML using UTF-8 character encoding so text and symbols (including international characters) render correctly.

UTF-8 means Unicode Transformation Format, 8-bit: it is a way to store any character as 1 to 4 bytes, and after decoding those bytes the browser/app gets real Unicode characters (letters, symbols, emoji) it can display and process as text.

name="viewport" content="width=device-width, initial-scale=1.0" - tells mobile browsers to use the device’s screen width and load the page at normal zoom so responsive layouts display correctly.
